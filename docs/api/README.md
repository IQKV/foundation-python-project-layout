## 📜 API Documentation

The service exposes an OpenAPI 3 schema generated by FastAPI.

| Resource        | URL                              |
| --------------- | -------------------------------- |
| Swagger UI      | `http://localhost:8080/docs`     |
| ReDoc           | `http://localhost:8080/redoc`    |
| OpenAPI schema  | `http://localhost:8080/openapi.json` |

### Endpoints

#### `GET /health`

Liveness probe. Returns `200` while the process is running.

```json
{ "status": "ok" }
```

#### `GET /ready`

Readiness probe. Returns `200` when the service is ready to serve traffic. Add
dependency checks (database, broker) here as the service grows.

```json
{ "status": "ready" }
```

#### `GET /api/v1/ping`

Smoke-test endpoint returning basic service identity.

```json
{
  "pong": "foundation-python-project-layout",
  "version": "0.1.0",
  "environment": "local"
}
```

### Adding an endpoint

Create a router in a domain module and include it in
`foundation_python_project_layout.main.create_app`:

```python
from fastapi import APIRouter

router = APIRouter(prefix="/api/v1/items", tags=["items"])


@router.get("")
async def list_items() -> list[dict[str, str]]:
    return []
```

Document request/response bodies with Pydantic models so they appear in the
OpenAPI schema automatically.
